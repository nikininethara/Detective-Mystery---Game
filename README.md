# Detective Mystery Game

A simple text-based detective mystery game created using Python.

## About the Game

In this game, you play as a detective investigating a diamond theft.
You can explore different options, collect information, and identify the person responsible for the crime.

## Features

- Interactive text-based gameplay
- Different locations and choices
- Multiple suspects
- Investigation and clues
- A final decision to solve the mystery

## How to Run

1. Make sure Python is installed.
2. Download or clone this repository.
3. Run the Python file.
4. Follow the instructions displayed in the terminal.
